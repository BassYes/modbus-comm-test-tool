## 1. 已实现功能（对应规划需求编号）

| 需求 | 内容 | 实现要点 |
|---|---|---|
| R-01 | 扫描指定串口下的设备 | 默认探测模板 `03→04→01→02`（地址 0、数量 1），默认超时 500 ms；**R-17 新增手动探测模式**（自选只读功能码 / 起始地址 / 数量）；合法异常响应也判定在线；可读设备标识（43/14）；**绝不使用写功能码与广播**（服务层 + 事务层双重门禁） |
| R-02 | 扫描指定设备下的数据 | 四类标准数据区；按协议上限自动分批（125 / 2000 / 123 / 1968）；非法地址可二分细化定位有效区间 |
| R-03 | 寄存器定位（反查寄存器） | **新增**：一次采样、多次解释（类型 × 字节序 × 缩放，最多 80 种组合但只读一遍总线）；精确 / 区间 / 容差 / 变化 / 趋势 / 位变化 / ASCII 文本七种模式；候选按分值稳定排序，同时展示协议地址、原始寄存器与解释规则；默认过滤 NaN/Inf 与非法 BCD |
| R-04 | 手动报文与校验自动填入 | 字段构建或原始十六进制；RTU 自动回填 CRC-16（低字节在前）；TCP 自动计算 MBAP 长度并展示各字段；**R-19：显式选择 RTU/TCP，未连接设备也能生成与校验**，发送前校验协议一致性 |
| R-05 | 实时报文监视 | 毫秒时标、TX/RX 颜色 + 文字双重区分（可关闭着色）、暂停显示、解析开关、过滤、导出 TXT/CSV、JSONL 落盘记录（**新增按体积分卷**） |
| R-06 | 扫描同网段在线设备 | **新增**：ARP（SendARP）/ ICMP / TCP 端口探测；状态分级“已发现 / 端口开放 / Modbus 有响应 / 未确认”；固定工作协程限流 + 地址上限拦截 + 可选限速；**未确认 ≠ 离线** |
| R-08 | 子网掩码计算同网段 | 网络 / 广播地址、主机范围、地址数量、通配符、二进制、地址类型、同网段判断、主机列表（超限不展开） |
| R-09 | 日志开关与同级目录日志 | 默认关闭；关闭时**不创建、不写入任何文件**，仅保留最近 2000 条内存日志；开启后写入 `logs/debug-*.log`；目录不可写自动回退并提示。**M2.5**：日志/设置/`.running`/报文记录统一走 `AppPaths`，便携优先、不可写回退 `%LOCALAPPDATA%` |
| R-10 | 扩展接口与位置 | `Comm.Plugins.Abstractions` 定义插件清单、能力声明、解析器 / 传输 / 校验 / 导出扩展点；**M3b 新增宿主 `Comm.Plugins.Host`**：只加载程序目录 `plugins\` 下的插件（清单校验、独立 `AssemblyLoadContext`、注册超时 5 s、连续失败 3 次自动禁用并持久化）、**扩展中心页**可视化启停，附参考示例插件 |
| — | 监视表 | **新增**：点位（数据区 / 地址 / 类型 / 字节序 / 缩放 / 单位）周期刷新，变化标记与上次值，连续地址合并成一次请求，`Periodic` 优先级（低于手动发送、高于扫描），CSV 导出 |
| — | 扫描方案 / 报文模板 / 设备目标持久化 | **新增**：设置文件 schemaVersion 升到 **2**，v1 自动迁移且不丢原字段；方案只存“选项快照”（向前兼容）；写模板带风险标签，重发需再次确认 |
| R-11 | **设备扫描：未知波特率 / 未知校验位** | **M2.5 完成**：设备扫描页新增“串口参数”区（使用连接中心 / 指定 / **未知**）；两阶段扫描（阶段 A 少量地址定位参数 → 阶段 B 扫完整地址段 + 3/3 确认）；结果表新增波特率/校验/停止位与“推荐”；一键“应用到连接中心”；四种终态都恢复原参数；静默阈值与响应超时随波特率变化 |
| R-07 / R-13 | 网卡配置 / 辅助 IP | **M3a 完成**：网络工具页可配置本机网卡静态 IPv4 / 掩码 / 网关 / DNS、切换 DHCP、叠加与移除辅助 IP；写操作全部交给提权助手 `Comm.NetConfigHelper.exe`（UAC 按需拉起、固定命令白名单）；应用前自动保存快照、回读校验、失败自动回滚、可一键恢复；可选安全恢复倒计时（默认关，勾选后默认 60 s，由助手持有） |
| R-12 | TCP Unit ID 扫描 | **M4 完成**：Modbus TCP 网关（后挂 RS-485）逐个 Unit ID 找在线从站；探测规则与串口设备扫描完全一致（自动模板 / 手动只读模板 / 异常响应判在线），**默认串行**、并发度 1~8 需二次确认，每个 Unit ID 恰好探一次；支持暂停/停止、CSV 导出、设为默认 Unit ID、保存为设备目标、扫描方案 |
| R-16 | 多会话与可拆分窗口 | **M3b 完成（第一阶段）**：会话注册表（上限默认 8，至少保留 1 个）、每会话独立的连接/统计/监视/监视表、串口按 `COMx` 全局独占、会话标签栏与“拆分到新窗口 / 移回主窗口”、窗口位置按会话持久化；跨窗口拖拽停靠留 v1.x |
| R-20 | 消除“无法验证发布者”警告 | **M2.5**：签名流水线可运行（测试证书联调）、便携包附解除锁定脚本、证书采购清单与验证矩阵已交付；正式证书待定案（Q-1） |
| R-21 | 适配其他电脑 | **M2.5**：默认 Release 自包含发布、数据目录回退、DPI/执行级别 manifest、应用图标与版本资源、最小窗口 900×480、导出用 `InvariantCulture`、串口与网卡兼容提示、环境自检、版本号单一来源 |

## 3. 构建与运行

本机仅在用户目录安装了 .NET 8 SDK（未安装 Visual Studio）：

```bash
DOTNET=C:/Users/Bass/.dotnet/dotnet.exe        # SDK 8.0.426
cd "E:/Download/DSH/通讯测试工具-v0.1"
$DOTNET build CommTestTool.sln                 # 构建全部
$DOTNET run --project src/Comm.App.Wpf        # 运行界面
```

运行产物：`src/Comm.App.Wpf/bin/Debug/net8.0-windows/CommTestTool.exe`

**给其他电脑用请不要复制 `bin/Debug`**（里面有 pdb 与中间文件，也最容易被搬来搬去染上“来自网络”标记）。
请走发布脚本，产物只从 `artifacts\publish` 出：

```powershell
# 默认：Release + 自包含 win-x64 单目录（目标机无需预装 .NET 8 Desktop Runtime）
.	ools\Publish-App.ps1

# 签名 + 打成便携包（zip 内已附“便携包说明.txt”与“解除锁定-便携包.ps1”）
.	ools\Publish-App.ps1 -Sign -Zip -TimestampServer http://timestamp.digicert.com

# 可选的“框架依赖小包”（体积小，但目标机必须预装 .NET 8 Desktop Runtime）
.	ools\Publish-App.ps1 -FrameworkDependent

# 额外把参考示例插件装进 plugins\Sample（现场演示/自检用）
.	ools\Publish-App.ps1 -WithSamplePlugin
```

M3 起发布目录固定包含三部分：

```
artifacts\publish\
  CommTestTool.exe                 主程序（始终以普通用户运行）
  helper\Comm.NetConfigHelper.exe 网卡配置提权助手（点“应用配置”时才按需 UAC 拉起；必须与主程序一起签名）
  plugins\                        插件受信目录（只加载这里的插件；含“插件目录说明.txt”与“插件目录说明”）
```

**数据目录策略（R-21 X-2）**：程序目录可写 → 程序同级 `data/`（便携）；不可写（如 `Program Files`、只读 U 盘）→
自动回退 `%LOCALAPPDATA%\通讯测试工具\data`。实际目录与回退原因在“设置与日志”页可见，并可在那里创建
`portable.flag` 或在便携↔用户目录之间迁移设置。

> 说明：本机环境下 VSTest 的 `testhost` 会被拒绝访问父进程句柄（`Win32Exception (5)`），因此额外提供了 `Comm.TestRunner`：它用反射直接执行同一批 xunit 用例，不依赖 VSTest，便于受限环境下自检。用例本身是标准 xunit，正常环境可直接 `dotnet test`。

覆盖重点：

- CRC-16 标准向量（`01 03 00 00 00 0A` → `C5 CD` 等）、252 字节上限。
- RTU 成帧：整帧 / 逐字节 / 任意切分点 / 粘包 / 噪声 / 校验错误后滑动重同步 / 未知功能码靠静默定界 / 主站模式下跳过其他从站流量。
- TCP 成帧：任意切分点重组、一个块内两个 ADU、长度字段非法、协议标识非 0。
- 事务层：正常读写、地址不符超时、重试计数、异常响应不重试且作为有效结果、校验错误可重试、**未确认写被守卫拒绝**、广播写需专项确认、RS-485 回显抑制、取消、单链路串行化、TCP 事务标识配对。
- 扫描：仅在线地址被发现且不产生任何写功能码请求、异常响应判为在线、数据区读取、非法地址二分细化、离线全超时。
- 手动报文：CRC 自动生成与回填、写操作二次确认、校验错误帧默认阻止发送。
- 数据解码：`ABCD/BADC/CDAB/DCBA` 四种字节序下的 Float32/Float64、16/32 位整数、BCD、ASCII、NaN 与非法 BCD 识别、缩放与偏移、编解码互逆。
- 子网计算：`/24`、`/23`、`/31`、`/32`、多种掩码写法、同网段判断、非法输入与非连续掩码、地址分类、超限不展开。
- 寄存器定位：精确/缩放/容差/区间/变化/趋势/位变化/文本命中、排序稳定、候选上限、NaN 与非法 BCD 过滤、参数自检、取消与导出；并断言“一次采样、多次解释”（全程只发 1 次读请求）。
- 监视表：点位增删、周期读取（`Periodic` 优先级）、连续地址合并、变化标记与上次值、位区解码、与扫描任务并行不破坏 CC-1、导出。
- 局域网扫描：范围构建（CIDR / 简写范围 / IP+掩码）、超限拦截（VAL-4007）、状态分级、**未确认 ≠ 离线**、并发限流、取消、单主机超时隔离、真实 TCP 端口探测、导出。
- 基础设施：设置 v1→v2 迁移不丢字段、方案负载向前兼容、更高版本只读、损坏文件备份、报文落盘分卷与释放幂等、关闭协调器幂等/顺序/异常隔离。

> 现场反馈回归（M2 一并修复）：程序关闭不再报 `IAsyncDisposable` 错误；新一轮扫描不再沿用上一轮提示；网络工具二进制与设备标识选项不再被截断；串口连接后会锁定参数并显示实际参数。

## 5. 几个关键实现决策（对应规划章节）

1. **RTU 分帧以长度预测为主、静默判定为辅**（规划 14.3.2）。Windows + USB 转串口下毫秒级静默不可靠，因此按功能码预测响应长度；未知功能码才在静默事件上收尾；CRC 失败时滑动重同步并保留噪声字节记录。
2. **必须先登记待配对响应，再发送**（规划 13.3/14.5）。设备响应可能极快，先发后登记会丢响应造成假超时；代码中该顺序有注释保护。
3. **回显抑制有明确边界**（规划 14.2.2）。只在“响应必然与请求不同”的读功能码上按字节抑制 RS-485 回显；写单个/多个线圈与寄存器（05/06/0F/10）的响应可能与请求逐字节相同，此时一律不抑制，避免丢掉真实响应。
4. **日志开关语义**（规划 4.10.1）。关闭时连文件句柄都不创建；崩溃报告不受开关控制（可单独关闭）；目录不可写时回退到用户目录并在界面提示。
5. **背压策略**（规划 13.5）。落盘队列不丢记录（满则报警）；显示缓冲超上限丢最旧的显示条目并显示丢弃计数，落盘不受影响；暂停显示期间采集与落盘继续。
6. **报文数据流**（规划 13.5）。通信路径只做收发与打时标，解析、格式化、落盘、界面刷新都在其他路径；界面按 50 ms 批量投递，不逐条跨线程回调。

## 7. 现场自测建议

1. **不用硬件**：连接中心选 TCP，目标 `127.0.0.1:502`（若无设备会连接失败，属正常提示）；更完整的自测见测试用例。
2. **串口设备**：`刷新串口` → 选择口与参数 → `打开串口` → 设备扫描（先用小范围地址，如 1~32；参数不明时把
   “波特率/校验位”选成 **未知（自动尝试）**，程序会先在两三个地址上定位参数、再扫描完整地址段，找到后可用
   “应用到连接中心”一键回填）→ 用发现的地址做数据扫描 → 报文工具手工发一帧（未连接也能先生成 TCP 报文）→ 报文监视核对原始报文与解析。
3. **反查寄存器**：数据扫描看到可疑量值后，到“寄存器定位”页填目标值，在范围内反查候选，再把候选“加入监视表”持续观察。
4. **局域网排查**：网络工具算出网段 → 局域网扫描（先小范围）→ 对开放 502 的主机“设为 TCP 连接目标”后到连接中心连接；Modbus 识别默认关闭，需要时再勾选。
3. **日志**：打开右上角“Debug 日志”开关（或在设置页开启），确认程序同级 `logs/` 下生成 `debug-*.log`；关闭开关后确认不再新建文件。
4. 遇到问题请用设置页“复制诊断信息”或“生成诊断包”反馈（仅保存在本机，不会自动上传）。
