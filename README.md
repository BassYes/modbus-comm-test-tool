# 通讯测试工具 · Modbus RTU / Modbus TCP 现场调试

一个中文界面的 Windows 桌面工具，给现场调试和运维用：**连上串口或 TCP 从站，扫描设备、扫数据、定位寄存器、盯着报文看、手工收发、顺带排查局域网和本机网卡**。

> 适用：电力 / 工业现场的 Modbus 设备联调、验收、故障定位。
> 不适用：作为长期运行的采集网关（它是调试工具，不是 SCADA）。

---

## 1. 能做什么

| 功能 | 说明 |
|---|---|
| **连接** | 串口（可选波特率/数据位/校验/停止位）或 Modbus TCP；支持多会话与拆分窗口 |
| **设备扫描** | 在指定串口上扫从站地址；支持**未知波特率 / 未知校验位**两阶段扫描，并给出推荐参数 |
| **数据扫描** | 四类标准数据区（03/04/01/02），按协议上限自动分批，非法地址可二分定位有效区间 |
| **寄存器定位（反查）** | 一次采样、多组合解释（类型 × 字节序 × 缩放，最多 80 种），七种模式找“这个值对应哪个寄存器” |
| **报文监视** | 毫秒时标、TX/RX 区分、暂停、解析开关、过滤、导出 TXT/CSV、JSONL 落盘（按体积分卷） |
| **手工发送** | 字段构建或原始十六进制；RTU 自动算 CRC-16，TCP 自动算 MBAP 长度；未连接也能生成与校验 |
| **监视表** | 点位周期刷新、变化标记、连续地址合并请求、CSV 导出 |
| **局域网排查** | ARP / ICMP / TCP 端口三级探测，状态分“已发现 / 端口开放 / Modbus 有响应 / 未确认”；子网掩码与主机范围计算 |
| **TCP Unit ID 扫描** | 网关后挂 RS-485 时，逐个 Unit ID 找在线从站（默认串行，并发需二次确认） |
| **网卡配置** | 本机静态 IP / 掩码 / 网关 / DNS、切 DHCP、叠加辅助 IP；写操作交给提权助手，带快照与失败回滚 |
| **诊断** | 会话统计（TX/RX/超时/校验错误/异常响应…）、崩溃报告、诊断包、环境自检（仅本机生成，不上传） |

**安全约束**：扫描只用只读功能码，**绝不使用写功能码、绝不广播**；涉及写入的操作（参数写、网卡配置、带风险的报文模板）都要显式确认。

## 2. 下载哪个包

到仓库的 **Releases** 页面下载：

| 形态 | 文件 | 装到哪里 / 怎么用 |
|---|---|---|
| **安装版**（推荐） | `通讯测试工具-<版本>-安装包.exe` | 装到 `%LOCALAPPDATA%\Programs\通讯测试工具`，创建开始菜单与桌面快捷方式（可选）。**不需要管理员，安装全程不弹 UAC** |
| **便携版** | `CommTestTool-v<版本>-win-x64.zip` | 解压到任意可写目录，双击 `CommTestTool.exe`；配置留在程序旁的 `data\`。适合多人共用的调试工位或不方便安装的现场机 |

- 两个包都是**自包含发布**，目标机无需预装 .NET。
- 安装版是**当前用户安装**：每个 Windows 账号各装一份；多人共用一台机器建议直接用便携版。
- 卸载**不会删除**你的配置与日志（数据在 `%LOCALAPPDATA%\通讯测试工具\` 下）。

## 3. 系统要求

- Windows 10 21H2（内部版本 19044）及以上，或 Windows 11，**x64**
- 串口：USB 转串口需装对应驱动（CH340 / CP210x / FTDI 等）
- 网卡配置功能：首次点击“应用配置”时会弹 UAC，拉起提权助手（`helper\Comm.NetConfigHelper.exe`），仅此一处需要管理员
- 杀软/防火墙：程序本身不监听端口；局域网扫描是主动探测，可能被目标主机防火墙影响

## 4. 五分钟上手

1. **连接**：连接中心选串口或 TCP，填参数后连接（串口参数不确定就先去设备扫描页用“未知波特率”模式）。
2. **找设备**：设备扫描 → 选串口 → 扫地址段。
3. **看数据**：数据扫描 → 选数据区与地址范围 → 导出 CSV。
4. **盯报文**：监视页打开实时刷新；排障时开 `Debug 日志`。
5. **发给别人**：设置页“复制诊断信息”或“生成诊断包”（仅保存在本机）。

小技巧：`CommTestTool.exe --page=N` 可直接打开第 N 个功能页（1–12：会话页 1–8，全局页 9–12）。

界面截图见 `docs/screenshot-*.png`；更细的操作说明见 [用户手册](docs/用户手册.md)。

## 5. 数据、日志与导出放在哪

| 形态 | 数据 / 日志 / 导出位置 |
|---|---|
| 便携版（解压即用） | 程序目录下 `data\`、`logs\`、`exports\` |
| 安装版 | `%LOCALAPPDATA%\通讯测试工具\data\`、`…\logs\`、`…\exports\` |

- 想强制便携：在程序目录放一个空文件 `portable.flag`（设置页有一键创建）。
- 安装版与便携版之间的配置可以在设置页互相迁移。
- 日志默认**关闭**；关闭时不创建任何日志文件。设置页与启动日志都会显示实际使用的目录。

## 6. 常见问题

**Q：提示“无法验证发布者”，或“Windows 已保护你的电脑”？**
程序目前**未做代码签名**。从网盘/微信/邮件拿到的 exe 会带“来自 Internet”标记，Windows 因此提示。三种处理：
1. 用**安装包**安装：安装器写出的文件不带该标记，装完启动不再提示；
2. 便携包：右键 zip → 属性 → 勾选“解除锁定”后再解压（或解压后运行包内 `解除锁定-便携包.ps1`）；
3. 彻底解决需要正式代码签名证书，选型见 [代码签名计划](docs/code-signing-plan.md)。

**Q：双击安装包没弹 UAC，正常吗？**
正常。v0.4.2 起安装包是当前用户安装（`lowest` 权限），本来就不提权。

**Q：串口打不开 / 报“拒绝访问”？**
被其他程序占用（含上一次没退干净的实例）、驱动未装、或 COM 号 ≥10 被个别旧工具限制。先关掉占用程序，或在设备管理器把端口号改小。

**Q：网卡配置点了没反应？**
第一次会弹 UAC 并启动提权助手，**必须允许**；拒绝则写操作会失败。助手只接受固定命令，不会执行任意命令行。

**Q：局域网扫描结果“未确认”是不是离线？**
不是。未确认只代表 ARP/ICMP/TCP 三种探测都没回应，可能被防火墙或隔离策略挡了。

**Q：更新怎么做的？**
软件内可检查更新，下载后校验 **Ed25519 签名 + 大小 + SHA-256 + 版本号**，通过才替换程序；校验失败不会替换。

**Q：卸载后我的配置还在吗？**
在。安装版卸载只删程序文件，`%LOCALAPPDATA%\通讯测试工具\` 下的数据保留；需要彻底清理请手动删除该目录。

## 7. 隐私与许可

- 程序**不会**自动把任何数据发到网络；日志、报文记录、诊断包只存在本机，除非你自己导出并发送。
- 检查更新时才会访问 GitHub Releases（可在设置中关闭）。
