## 4. 结论

**v0.4.0 达到“可交付给现场试用”的状态，但尚不满足 v1.0 正式发布条件。** 剩余阻塞项集中在三类外部依赖：

1. **正式代码签名证书（Q-1）** —— 决定 R-20 能否对外彻底解决（UAC/SmartScreen 提示）。
2. **干净机 + 隔离虚拟机** —— 干净机冒烟、网卡提权写入与倒计时回滚、DPI 矩阵。
3. **真实硬件** —— 硬件在环矩阵、24 h 稳定性、1000 帧/s 界面可操作性。

建议：先定案证书并借到硬件，再按本清单第 1 节第 7/12/14/16/18/19 项与第 2 节第 23/24 项收尾，之后即可发布 v1.0。
