## 2. R-11：设备扫描的“未知波特率 / 未知校验位”

### 2.1 界面（规划 22.3.2）

设备扫描页左侧“扫描参数”区新增：

- **波特率**：`使用连接中心参数` / `指定（1200~115200）` / **`未知（自动尝试）`**（默认使用连接中心参数）
- **校验位**：`使用连接中心参数` / `指定（N/E/O）` / **`未知（自动尝试）`**
- **候选波特率**（仅“未知”时可见）：8 个波特率多选 + `常用优先` 开关（默认全选、开启）
- **高级（折叠）**：停止位策略（自动 / 固定 1 / 固定 2）、阶段 A 探测地址、命中后是否继续其他组合、参数更换稳定等待、命中后确认次数
- **预计耗时**：显示“组合数 × 阶段 A 地址数 × 超时 + 阶段 B 估计”，超过 10 分钟时开始前二次确认
- 结果表新增列 **波特率 / 校验 / 停止位 / 推荐**；新增按钮 **“应用到连接中心（R-11）”**（可一键回填并选择立即重连）

面板固定区新增一行“当前 / 原”串口参数提示，例如 `当前 19200-8-E-1（原 4800-8-N-1）`，满足规划 22.3.4 第 3 点的状态一致性。

### 2.2 两阶段算法（规划 22.3.3）

- **阶段 A（定位参数）**：对每个组合只对少量候选地址（默认 `1~10, 247`，可用“已知地址”覆盖）发**一次只读探测**（03 读 1 个寄存器、起始地址 0）。合法正常响应或合法异常响应都算命中 → 阶段 A 一轮共 `组合数 × 地址数` 次请求。
- **阶段 B（扫描地址）**：命中的组合上按 4.2.2 规则扫描完整地址段；命中地址再重复探测 2 次，**3/3 全通过才记“在线”**，否则记“疑似”。
- 默认命中后完成该组合的阶段 B 即结束；勾选“继续其他组合”则遍历剩余组合。
- **多组合同时命中**：按组合分组全部列出，只标注一个“推荐”（规则：无 CRC 错误 → 在线数多 → 停止位少 → 波特率低），**不自行断言唯一正确**。
- 只收到校验错误帧时按“杂乱数据”计数并提示“设备可能存在但参数不完全匹配”。
- 每个组合切换在日志里写一条说明记录（不产生 TX/RX 假帧）。

### 2.3 与现有实现的衔接（规划 22.3.4）

| 要点 | 实现 |
|---|---|
| **1. 静默阈值随波特率变化（F-5）** | 新增 `Comm.Protocols.Modbus.RtuTiming`：阈值 = `max(用户阈值, ⌈3.5×11 位 ÷ 波特率⌉ + 1, 5 ms)`。1200 bps → **34 ms**（旧实现固定 5 ms 会误拆帧）、9600 → 6 ms、≥38400 → 5 ms。**响应超时**同样抬到 `max(用户值, 两帧传输时间 + 100 ms 设备处理余量)`（1200 bps 8 字节 → 247 ms）。`SessionManager.OpenSerialAsync` 统一应用 |
| **2. 端口重配用注入接口** | `ISerialReconfigurator`（定义在 `Comm.Scanning`，`SessionManager` 实现）；更换参数 = 关串口 + 清缓冲 + 重开 + 稳定等待（默认 150 ms，可配）。`Comm.Scanning` 不引用 WPF，分层未被破坏 |
| **3. 四种终态恢复原参数** | 恢复在 `finally` 中执行且**不受取消令牌影响**（自带 8 s 超时）；失败时明确置“未连接”并弹窗提示，不静默停留在错误参数。用例覆盖：正常完成 / 取消 / 重配失败 / 全部超时 |
| **4. 只读与单事务** | 阶段 A 固定 03、阶段 B 沿用 `DeviceScanOptions.Validate` 只读门禁；用例断言全部请求 `Fn.IsRead` 且无广播 |
| **5. 总线影响提示** | 开始前强制二次确认（说明会以不同波特率在总线上发只读请求） |
| **6. 方案兼容** | 方案负载升级为 `DeviceScanPlan { Scan, Parameters }`；旧方案（M2 扁平形状）读取时回退，**不升 `schemaVersion`**，缺字段默认“使用连接中心参数”。界面对旧方案给出提示 |
| **7. 监视与日志** | 参数扫描期间监视表周期读取自动暂停并在结束后恢复；每个组合切换写入日志 |

### 2.4 验收口径（规划 22.3.6）

- 模拟器设备设为 `19200-8-E-1`、地址 5，选“波特率未知 + 校验位未知”：用例 `Finds_a_device_that_only_answers_at_19200_even_parity_and_restores_original_parameters` 用参数感知模拟器验证“只在目标组合命中、3/3 确认、恢复原参数、唯一推荐”。
- 已知地址（1 个）时耗时约 `组合数 × 超时`：默认 32 组合 × 60~500 ms，属于秒级；默认多地址时由界面“预计耗时”如实展示，超 10 分钟要求二次确认。
- 真实硬件复核纳入第 6 项（待硬件）。
