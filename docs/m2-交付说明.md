## 3. 安全与约束回归

| 约束 | 保障方式 | 验证 |
|---|---|---|
| CC-6 扫描类任务不产生写功能码 | `DeviceScanOptions.Validate`（`VAL-4006`）+ `DeviceScanService.ScanAsync` 门禁 + 事务层守卫 | `Scan_service_refuses_write_function_even_if_validation_is_bypassed`、`One_sampling_pass_serves_every_interpretation_and_never_writes`、既有 `Device_scan_finds_only_online_addresses_and_never_writes` |
| 写操作二次确认 | 报文工具沿用 `ConfirmWrite`；模板保存 `IsWrite` 标签并在界面提示重发风险 | `Sending_a_tcp_frame_over_an_rtu_session_is_blocked`、模板风险文案 |
| CC-1 单链路单事务 | 监视表使用 `RequestPriority.Periodic`；寄存器定位复用 `DataScanService`（一次采样） | `Watch_refresh_interleaves_with_scan_without_breaking_cc1`、`One_sampling_pass_serves_every_interpretation...` |
| 不谎报在线 | 局域网扫描“未确认 ≠ 离线”，ARP 无 MAC 不判离线 | `Unresponsive_host_is_unconfirmed_not_offline`、`Host_state_follows_the_probe_result` |
| 扫描不把内网打爆 | 固定工作协程 + `MaxAddresses` 拦截 + 可选全局限速 + 大范围二次确认 | `Concurrency_is_bounded_and_results_are_sorted_by_ip`、`Range_over_the_limit_is_rejected_without_expanding` |
| 老设置不丢 | v1→v2 迁移保留原字段并立即落盘 | `Version_1_file_is_migrated_without_losing_existing_values` |
| 更高版本设置只读 | 版本高于当前时使用默认值并提示 | `Higher_version_file_is_read_only_with_defaults` |
| 退出不遗留异常 | 关闭协调器幂等 + 顺序 + 异常隔离 | `ShutdownCoordinatorTests` 4 个用例 + 10 个页面的人工关闭验证 |

## 5. 已知限制与后续建议

1. **多会话与可拆分窗口（R-16）未做**：仍在 M3。`SessionManager` 仍是单会话；实施前必须改成会话注册表 + 会话作用域 ViewModel。
2. **局域网扫描的 MAC 厂商（OUI）查询未做**（需要离线数据文件），主机名反查默认关闭以控制耗时。
3. **寄存器定位不做自动确认**：只排序并展示解释规则（规划 4.4.6 的误判控制），候选上限默认 200。
4. **趋势模式需要 ≥3 轮采样**：界面默认 2 轮，选择趋势模式时参数校验会提示（`ValidationBadInput`）。
5. `PduKind` 位区显示问题（D-6）与 UI 文案本地化（D-5）仍待处理。
6. 便携版仍无代码签名与安装包（M4）。
