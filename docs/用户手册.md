# 通讯测试工具 用户手册（v0.4.0）

> 适用版本：v0.4.0（M4 加固与发布）。目标场景：电力工业现场的 Modbus RTU / Modbus TCP 调试。
> 本手册面向**现场调试人员**，按“装、连、扫、看、发、配、排”的顺序组织。
> 界面细节以实际版本为准；技术细节与设计依据见 `docs/m3-交付说明.md`、`docs/m4-交付说明.md`。

---

## 1. 安装与启动

### 1.1 两种分发形态

| 形态 | 适用场景 | 获取方式 | 说明 |
|---|---|---|---|
| **安装包**（推荐给网络渠道） | 通过网盘/微信/QQ/邮件/下载获得 | `artifacts\installer\通讯测试工具-<版本>-安装包.exe`（需 Inno Setup 构建）或 **便携安装包 zip** | 安装后程序文件不带“来自网络”标记，**启动时不再弹“无法验证发布者”** |
| **便携包** | U 盘、内网共享、免安装 | `artifacts\publish\` 整目录，或同名 zip | 解压即用；从网络获得时需先“解除锁定”（见 `便携包说明.txt`） |

### 1.2 系统要求

- Windows 10 21H2+ / Windows 11，**x64**。
- **无需预装 .NET**：发布包为自包含（含运行时）。
- 主程序以**普通用户**运行；只有“应用网卡配置”时才按需弹出 UAC（由独立提权助手执行）。
- 建议屏幕 ≥ 1280×720；最小可用窗口 900×480（125%/150% 缩放的小屏笔记本可用）。

### 1.3 目录约定

```
<程序目录>\
  CommTestTool.exe                 主程序
  helper\Comm.NetConfigHelper.exe  网卡配置提权助手（勿删）
  plugins\                         插件受信目录（只加载这里的插件）
  data\                            便携模式下的设置与报文记录
  logs\                            Debug 日志 / 崩溃报告
  exports\                         导出文件默认目录
```

- 程序目录**不可写**时（如装在 `Program Files`），数据自动回退到
  `%LOCALAPPDATA%\通讯测试工具\data`、日志回退到 `%LOCALAPPDATA%\通讯测试工具\logs`。
  实际使用的目录在“设置与日志”页可见，启动日志里也会写一行。
- 卸载/清理：安装版走“应用和功能”；便携版删除程序目录即可（用户数据目录默认保留）。

### 1.4 首次启动会看到什么

- 若上次异常退出：提示“检测到上次运行异常退出”，并给出崩溃报告路径（可在设置页关闭崩溃报告）。
- 若上次修改网卡后没点“保留此配置”：会提示“检测到未决的网卡配置快照”，可选择立即恢复。
- 顶部工具栏右侧是 **Debug 日志开关**（默认关闭，关闭时不产生任何日志文件）。

## 2. 界面总览

### 2.1 会话页（每个会话各有一套）

| # | 页面 | 用途 |
|---|---|---|
| 1 | 连接中心 | 串口 / TCP 连接、常用设备目标、连接状态 |
| 2 | 设备扫描 | 串口从站地址扫描（含未知波特率/校验位的两阶段扫描） |
| 3 | Unit ID 扫描 | Modbus TCP 网关后面的 Unit ID 扫描（R-12） |
| 4 | 数据扫描 | 四类数据区读取、数据类型/字节序解释、加入监视表 |
| 5 | 寄存器定位 | 已知值反查寄存器地址（精确/区间/容差/变化/趋势/位/文本） |
| 6 | 监视表 | 周期刷新点位、变化标记、导出 |
| 7 | 报文工具 | 手工报文、CRC/MBAP 自动计算、循环发送 |
| 8 | 报文监视 | 实时收发记录、暂停显示、过滤、保存 |

### 2.2 全局页（所有会话共享）

| # | 页面 | 用途 |
|---|---|---|
| 9 | 网络工具 | IPv4 子网计算 + **本机网卡配置**（IP/掩码/网关/DNS/辅助 IP） |
| 10 | 局域网扫描 | 同网段设备发现（ARP/ICMP/TCP 端口 + 可选 Modbus 识别） |
| 11 | 扩展中心 | 插件清单、能力/风险、启用/禁用 |
| 12 | 设置与日志 | 日志、显示、会话与工作区、环境自检、诊断包 |

> 页序号也是命令行参数：`CommTestTool.exe --page=11` 直接打开扩展中心（排障/截图用）。

### 2.3 多会话

- 顶部**会话标签栏**：「新建会话」「拆分到新窗口」「移回主窗口」「关闭会话」。
- 每个会话有**独立的**连接、统计、报文监视与监视表；一个会话扫描不影响另一个。
- **同一个串口不能被两个会话同时打开**（会提示“COM3 已被会话「会话 1」占用”）。
- 会话上限默认 8（设置页可调）；至少保留 1 个会话。
- 关闭拆分窗口时三选一：取消 / 保持会话并移回主窗口 / 取消任务并关闭会话。

### 2.4 底部状态栏

`已连接 COM3（modbus-rtu）· 4800,8,N,1 · 超时 1000 ms · 重试 2` —— 显示的是**连接成功时的参数快照**，不会因为你在编辑框里改了参数就变。

同时显示 TX/RX/超时/校验错误/异常响应/未匹配计数、当前任务与进度、监视状态、会话数。

## 3. 建立连接

### 3.1 串口

1. 连接中心 → 选择端口（可「刷新」）→ 设置波特率/数据位/校验/停止位 → 打开串口。
2. 参数含义：
   - **响应超时**：从发完请求到收到完整响应的上限。低速波特率下工具会自动抬高到“帧传输时间 + 余量”。
   - **请求间隔（轮转延迟）**：RTU 相邻请求之间的最小间隔，默认 20 ms。
   - **重试次数**：仅对读请求默认重试；**写请求默认不自动重试**（避免重复写入）。
   - **抑制回显**：RS-485 半双工适配器会把自己发出去的帧收回来，默认开启自动识别。
3. 串口打开后会**锁定参数编辑**；要改参数请「关闭串口」→ 改 → 重新打开（避免界面值与实际链路不一致）。

### 3.2 Modbus TCP

1. 填目标 IP（或主机名）与端口（默认 502）、Unit ID、连接超时。
2. 可先「连接测试」；连接后底栏显示本地/远端端点。
3. 多个 TCP 会话可指向同一目标，各自独立连接（互不影响）。

### 3.3 常见连接问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `COM3 被其他程序占用` | 串口被别的软件打开 | 关闭占用程序；或换端口 |
| `无法打开串口 COM10` | 端口不存在/驱动未装 | 设备管理器确认端口；USB 转串口常见驱动：CH340 / CP210x / FTDI |
| 连不上 TCP 目标 | 网段不对 / 防火墙 / 端口非 502 | 先用「网络工具」的子网计算确认同网段；用局域网扫描查 502 端口 |
| 全部请求超时 | 波特率/校验位不对 | 用**设备扫描**的“未知波特率/未知校验位”自动试参数 |

## 4. 设备扫描（串口）

1. 打开串口 → 进入“设备扫描”。
2. 扫描范围：默认 `1~247`；也可只扫已知的几个地址（更快）。
3. **探测方式**：
   - **自动模板**（默认）：依次尝试 `03 → 04 → 01 → 02`（地址 0、数量 1），任一合法响应即判定在线。
   - **手动探测**：自选只读功能码（01/02/03/04）、起始地址与数量。写功能码**不允许**用于扫描。
4. **串口参数**（现场常见的“不知道波特率/校验位”）：
   - 波特率/校验位可选 `使用连接中心参数` / `指定` / **`未知（自动尝试）`**。
   - 选“未知”后，工具分两阶段：先用少量候选地址快速定位参数组合，再在命中的组合上扫完整地址段。
   - 结果表会显示命中的 **波特率/校验/停止位**，并可一键「应用到连接中心」。
   - 扫描结束（无论完成、停止、出错还是关窗）都会**恢复你原来的串口参数**。
5. 结果判读：`在线`（正常响应）、`疑似`（收到校验错误等杂乱数据，或确认次数不足）、`未发现`。
   **异常响应也算在线**（说明该地址有从站，只是不支持这个地址/功能码）。
6. 结果可导出 CSV、可把地址设为默认 Unit ID、可加入监视表。

> ⚠ 扫描只发只读请求，但参数未知时会用不同波特率在总线上发请求，**同总线其他设备可能把这些视为噪声**，开始前会二次确认。

## 5. Unit ID 扫描（Modbus TCP 网关场景）

适用于：TCP 网关后面挂 RS-485 总线，不知道总线上有哪些从站地址。

1. 先在连接中心建立到网关的 **TCP 连接**（本页不扫描串口）。
2. 起始/结束 Unit ID（默认 1~247）、超时、重试、间隔、确认次数。
3. **并发度**（默认 1 = 严格串行）：
   - 网关通常只允许 1~2 条并发连接；调高前请确认，工具会在并发 >1 时二次确认。
4. 探测规则与串口设备扫描**完全一致**（自动模板 03→04→01→02，或手动只读模板），
   同样**绝不使用写功能码与广播地址 0**。
5. 结果可「设为默认 Unit ID」「保存为设备目标」「导出 CSV」、保存/载入扫描方案。

## 6. 数据扫描与监视表

### 6.1 数据扫描

1. 选设备地址、数据区（线圈/离散输入/输入寄存器/保持寄存器）、地址范围。
2. 每批点数可留空（按协议上限自动拆分：01/02 ≤2000，03/04 ≤125）。
3. 显示设置：地址基准（协议 0-based / 文档 1-based / 3xxxx / 4xxxx）、数据类型、字节序/字序、缩放。
4. 结果表同时给出：协议地址、文档地址、**原始十六进制**、解析值、位视图、状态、更新时间、变化标记。
5. 大块请求遇到“非法数据地址”时可开启**分段细化**，自动定位有效区间。

### 6.2 监视表

- 把关心的点位“加入监视表”，设置刷新周期（≥200 ms）。
- 变化的值会标出，并显示上一采样值。
- 连续地址会合并成一次请求（减少总线负担）。
- ⚠ 监视表刷新使用**周期优先级**：可以被手动发送“插队”，但不会产生写操作。

## 7. 寄存器定位（反查地址）

已知现场读数（例如电压约 220 V、频率 50 Hz），但不知道寄存器地址时使用。

1. 选设备与地址范围（只支持寄存器区）。
2. 选模式：**精确值 / 区间 / 容差 / 变化 / 趋势 / 位变化 / 文本**。
3. 配置候选解释：数据类型 × 字节序 × 缩放（工具会一次采样、多次解释，**只读一遍总线**）。
4. 变化模式用“基准快照 → 现场操作 → 对比快照”的引导流程。
5. 候选结果按匹配度排序，并同时展示**解释规则与原始字节**；
   ⚠ 工具**不会**替你把候选项标记为“已确认”—— 同一组字节可能有多种解释，需你判断。

## 8. 报文工具与报文监视

### 8.1 手工报文

- 三种编辑方式：十六进制原始字节、按字段表单、ASCII 辅助。
- **Modbus RTU**：输入主体后自动计算并回填 CRC-16（低字节在前）；可锁定 CRC 字段以测试错误校验场景（会有醒目提示）。
- **Modbus TCP**：自动生成 MBAP（Length 自动计算、Protocol ID 恒为 0、Transaction ID 可自动递增/固定/手填）。**TCP 帧不加 RTU CRC**。
- 未连接设备也能生成/校验报文；只有「发送」需要活动连接。
- 十六进制输入宽松解析（空格、逗号、`0x`、大小写混用）；字符数为奇数时就地提示，不自动补位。
- 发送能力：单次、定时循环、指定次数；循环发送可随时停止。
- ⚠ **写操作**（05/06/0F/10）会醒目标记，发送前二次确认；广播写需专项确认；循环发送写请求会再次提示频率与目标。

### 8.2 报文监视

- 每条记录含：序号、毫秒时标（本地时间）、相对时间、方向（TX/RX/系统）、端点、原始十六进制、解析摘要、响应耗时、关联请求、标记（ECHO/LATE/UNMATCHED/GARBAGE）、校验结果、异常码。
- **两个不同的“暂停”**：
  - **暂停显示**：界面不再滚动，后台仍继续采集与落盘，恢复后补齐。
  - **停止采集**：不再写入监视器，但不主动断开连接。
- 解析开关：关闭后仍完整保存原始报文（只是不显示解析结果）。
- 过滤：方向、会话、从站/Unit ID、功能码、地址范围、时间、十六进制片段、仅错误/超时/异常。
- 保存：TXT / CSV / **JSONL 记录**（可按体积分卷，崩溃后最多丢最后一行）。
- 显示缓冲可设上限，超出时丢**最旧显示条目**并提示丢弃条数——**落盘不受影响**。

## 9. 网络工具：子网计算与本机网卡配置

### 9.1 子网计算

输入 IP + 掩码（`255.255.255.0` / `24` / `/24` 均可），得到：网络地址、广播地址、主机范围、地址数、可用主机数、通配符、二进制、地址类型（私有/环回/链路本地/组播…）、与第二个 IP 是否同网段。

### 9.2 本机网卡配置（R-07 / R-13）

> ⚠ **修改网卡会立即影响本机所有网络连接**。如果你正通过远程桌面/网络访问这台机器，可能直接断开。请在现场操作，或先启用“安全恢复倒计时”。

1. 选网卡（列表是只读枚举，含 DHCP 状态、多个 IPv4、网关、DNS、是否虚拟网卡）。
2. 编辑：静态 / DHCP、IPv4、掩码或前缀、默认网关（留空=不改）、DNS（可选，需勾选“同时应用 DNS”）。
   - **“替换网卡上现有地址”**：勾选=替换；**取消勾选=保留原地址、只叠加**（等价于辅助 IP）。
3. 「校验并预览」：显示规范化结果与风险提示（网络地址/广播地址会被拒绝）。
4. 「应用配置」：二次确认会列出目标网卡、将写入的值、风险与倒计时状态 →
   通过 **UAC 提权助手** 执行 → **应用后回读实际值**并显示。
5. 失败时：工具按修改前的**自动快照**回滚，并在对话框说明“已恢复/未能恢复”。
6. **安全恢复倒计时**（默认关闭，勾选后默认 60 s）：应用后必须在倒计时内点「保留此配置」，
   否则**自动恢复**。计时由提权助手持有——**即使主程序崩溃或被结束，也会恢复**。
7. 「配置快照」列表可一键恢复到任一历史快照；「网络配置方案」可保存/载入/删除常用配置。

### 9.3 辅助 IP（推荐用于临时接入其他网段）

- 「新地址 + 前缀 → 叠加」：保留网卡原有地址，额外添加一个地址；之后可单独「移除选中地址」。
- 比整体替换更安全，现场临时接入不同网段设备时优先用它。

## 10. 局域网扫描

1. 选网卡（默认物理且已连接的网卡；Hyper-V/VMware/VPN 等虚拟网卡会被标注），自动计算扫描范围，也可手填 CIDR 或起止 IP。
2. 探测方式可组合：ARP / ICMP / TCP 端口（默认 502）/ 对开放 502 的目标做一次只读 Modbus 识别（默认关闭）。
3. 状态分级：`已发现` / `端口开放` / `Modbus 有响应` / `未确认`。
   ⚠ **ICMP 无响应不等于设备离线**（防火墙常屏蔽 ICMP）。
4. 范围超过上限（默认 4096）会拦截并要求确认；并发默认 64，可调。
5. 结果可复制 IP/MAC、创建 TCP 会话、导出 CSV。

## 11. 扩展中心（插件）

- 只加载 `<程序目录>\plugins\<插件>\plugin.json` 描述的插件，其它位置一律不加载。
- 每个插件显示：Id、名称、版本、状态、能力、**是否可能写设备**、所需权限、失败原因。
- 可「启用 / 禁用 / 重新扫描」「创建插件目录」「打开插件目录」「复制诊断信息」。
- 插件自身缺陷被隔离：连续失败 3 次自动禁用（下次启动仍禁用，直到你手动启用），**不影响主程序**。
- ⚠ 插件是进程内代码，加载机制**不是安全沙箱**：只安装来源可信的插件。

## 12. 会话窗口、工作区文件（项目）

### 12.1 拆分窗口

「拆分到新窗口」把一个会话的页面放进独立窗口（连接与任务仍是该会话自己的）；「移回主窗口」收回。
窗口位置/尺寸/最大化状态按会话记忆；显示器被拔掉后会自动回到可见区域。

### 12.2 工作区文件（`.ctws`）

- 设置与日志页 → 会话与工作区：
  - 「保存为工作区文件」：把扫描方案、报文模板、设备目标、网卡方案、串口/TCP 模板存成一个工程文件。
  - 「打开工作区文件」：先预览（含内容校验问题清单），再选择「应用（替换）」或「应用（合并）」。
- 工作区**不含**日志/监视等运行期设置；文件损坏时工具会保留 `.bad-时间戳` 备份并用默认值启动；
  若文件版本高于当前程序，则以**只读**打开、不会覆盖你的文件。
- 勾选“启动时自动重新打开上次的工作区文件”后，启动会以**合并**方式载入。

## 13. 日志与诊断

- **日志开关**：顶部工具栏 & 设置页；默认关闭，关闭时**不创建、不写入任何文件**（内存保留最近 2000 条用于诊断）。打开后立即生效，无需重启。
- 日志目录：程序同级 `logs\`（不可写时回退 `%LOCALAPPDATA%`）。文件名 `debug-YYYYMMDD-HHMMSS.log`，按大小滚动。
- **崩溃报告**：`logs\crash-*.log`（不受日志开关控制，可在设置页关闭；默认保留 10 份）。
- **环境自检**：系统/架构/DPI/数据目录可写性/串口与驱动提示/网卡摘要/自身签名与“来自网络”标记 —— **仅本机生成，不上传**。
- **诊断包**：日志 + 环境自检 + 设置摘要（不含报文内容，除非你显式开启“原始报文写入日志”）。
- 隐私：本工具**不会**自动联网上传任何数据；日志只在本机。

## 14. 排障速查

| 现象 | 处理 |
|---|---|
| 启动时“无法验证发布者” | 用**安装包**安装（安装后不带网络标记）；或用便携包的 `解除锁定-便携包.ps1`。彻底解决需正式代码签名证书（见下） |
| UAC 提示“未知发布者” | 提权助手未签名。正式发布前会与主程序一起签名 |
| 复制 `bin\Debug` 到现场启动失败 | 不要这样做；用 `tools\Publish-App.ps1` 的发布产物 |
| 数据存不下来/设置不生效 | 程序目录不可写时已自动回退；到设置页看“实际数据目录”，或创建 `portable.flag` |
| 串口扫描全是“未发现” | 波特率/校验位可能不对 → 用“未知波特率/未知校验位”；或地址范围不对 |
| 扫描很慢 | 空地址必然超时；减少地址范围、降低超时、避免重试；界面会预估最长耗时 |
| TCP 会话之间互相影响 | 不应该发生；多会话各自独立。若同一串口被两个会话使用会明确拒绝 |
| 修改网卡后断网了 | 等倒计时自动恢复，或插回原网段后到网络工具页恢复快照；也可在设置页查看未决快照 |
| 关闭程序时报错 | 先升级到 v0.4.0；若仍出现，收集 `logs\` 与崩溃报告反馈 |

## 15. 安全与授权

1. **只对已获授权的设备和网络操作**。扫描会在总线上产生流量，可能影响现场轮询。
2. 默认只读：所有扫描只用读功能码；**不会**自动写寄存器、不会自动广播。
3. 写操作必须二次确认；广播写单独确认；循环写再次提示。
4. 网卡修改前自动快照，失败自动回滚，可一键恢复；倒计时由提权助手持有。
5. 主程序始终以普通用户运行，只有网卡写操作经 UAC 提权助手；助手只接受固定命令集，**不执行任意命令**。
6. 不要求你关闭 UAC、SmartScreen 或杀毒软件。
7. 日志与报文只存本机，不上传。

## 16. 已知限制（本版本）

- 正式**代码签名证书未采购**：对外发布前必须先定案（否则网络渠道仍有安全提示）。签名流水线与安装包脚本已就绪。
- 安装包需要 Inno Setup 构建（本机未安装）；无 Inno 时脚本回退为“便携安装包 zip”。
- **跨窗口拖拽停靠**未实现（只提供明确的拆分/移回命令），规划留在 v1.x。
- 真实硬件的 24 h 稳定性、适配器/设备兼容性矩阵仍需现场回填（`docs/hardware-compatibility-matrix-v1.md`）。
- 界面语言仅简体中文（D-5 已决策：v1.0 不做多语言）。
- Modbus ASCII / RTU over TCP / 报文文件回放未实现（成帧层已预留）。
- TCP 一连接一事务，未启用流水线。
